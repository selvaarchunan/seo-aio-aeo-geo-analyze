# SEO, AIO, AEO & GEO Analyzer

An all-in-one analyzer powered by the Google Gemini API to evaluate and optimize your digital presence across traditional search engines and modern AI answering engines. Delivered as a lightweight, single-file HTML application.

---

## 🚀 Live Demo

Try the interactive tool directly in your browser:  
👉 **[Launch Live Demo](https://selvaarchunan.github.io/seo-aio-aeo-geo-analyze/)**

---

## ✨ Features

- **Multi-Vector Analysis:**
  - **SEO (Search Engine Optimization):** Evaluates metadata, on-page structure, and keyword distribution.
  - **AIO (AI Optimization):** Analyzes how well your content is understood and summarized by large language models.
  - **AEO (Answer Engine Optimization):** Assesses readiness for voice search, featured snippets, and direct question answering.
  - **GEO (Generative Engine Optimization):** Scores content for inclusion and citation across generative search platforms (e.g., Google AI Overviews, Perplexity).
- **Flexible Data Input:**
  - Live URL scraping.
  - Raw content/text paste.
  - JSON batch imports.
- **AI-Driven Scoring & Recommendations:** Leverages Google's Gemini API to generate deep, actionable optimization scores and specific suggestions.
- **Zero Install / Portable:** Built as a standalone single-file `index.html`—no build pipeline or backend server required.
